# Your Quarto website

- Upload the CONTENTS of `public-site/` to `smk5g5.github.io` for the ready-made website. Enable Pages from main/root.
- Keep the CONTENTS of `quarto-source/` in a PRIVATE repository called `website`. This is where you edit pages and write posts.
- Read `quarto-source/SETUP.md` for publishing automation and `quarto-source/README.md` for editing and draft instructions.
- To preview the generated site locally: `python3 -m http.server 8000 --directory public-site`, then open http://localhost:8000.

The example blog post is included. Cloudflare authentication has not been configured. The publication list still needs a full Scholar export to guarantee completeness.
